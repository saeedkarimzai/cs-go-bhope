# CS Bhop

A single-file first-person bunny-hop course built with Canvas and plain JavaScript.

## Run
Open `index.html` in a modern desktop browser. No build step, API, or external library is required.

## Controls
- Click **Play** and click the game view to lock the mouse.
- W/A/S/D — move and air-strafe.
- Space — jump.
- R — restart the run.
- Escape — release the mouse.

Best time is stored in browser local storage. The game is a browser movement demo, not a networked Counter-Strike game.
